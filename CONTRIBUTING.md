
# Contributing to twichionBOT

Thanks for your interest in helping twichionBOT!

## How to contribute

1. Fork this repository.
2. Create a branch for your changes.
3. Make your changes and test them.
4. Submit a Pull Request explaining what you changed.

## Contribution guidelines

- Keep the code readable.
- Do not commit API keys, passwords or tokens.
- Explain new environment variables in the README.
- Test your changes before submitting them.
- Keep pull requests focused on one improvement.

## Reporting bugs

Open a GitHub Issue and include:
- What happened.
- What you expected.
- Steps to reproduce the issue.
- Relevant error messages (without secrets).

Thank you for helping the project!
